# User Interface

對象：一般取餐者、訪客。目標是「掃一次、看得懂、離開也不用重掃」。

## 01 Entry / QR
- Venue QR
- Restaurant QR
- Order QR
- Deep link
- Invalid / expired QR

## 02 Home / Search
- Venue status
- Restaurant search
- Category filter
- Open-only filter
- Sort
- Empty results

## 03 Restaurant Detail
- Current queue number
- Recent numbers
- Enter ticket number
- Estimated wait
- Add to My Orders
- Passed-number handling

## 04 My Orders
- Multi-restaurant tracking
- Priority sorting
- Current / mine / groups ahead
- Estimated minutes
- Complete / remove
- Add another order

## 05 Session / Recovery
- Anonymous visitor session
- Persist active orders
- Restore last route
- Reopen without rescanning
- Duplicate QR prevention
- Cross-device recovery (future)

## 06 Notifications
- Permission request
- 10 / 5 / 3 / 1 groups reminder
- Now serving
- Passed number
- Deep link back to order
- Push delivery state

## 07 Public Board
- Venue-wide display
- Large-distance readability
- Open / paused state
- Auto refresh

## 08 Error / Offline
- Stale queue data
- Offline mode
- Reconnect
- Restaurant paused
- Restaurant closed
- Queue session reset

## 09 Accessibility
- Large text
- Screen reader
- Keyboard
- Contrast
- Color-independent statuses

## 10 User Analytics (privacy-aware)
- QR entry success
- Order added
- Reminder enabled
- Restore success
- Order completed
- No raw personal data in client analytics

## 主要驗收
使用者第一次進站後，3 秒內應能知道：
1. 現在叫到幾號
2. 自己是幾號
3. 前面還有幾組 / 約多久
4. 哪一張訂單最優先
