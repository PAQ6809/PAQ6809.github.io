# ReelScribe Store Asset Checklist

Final store imagery must be captured from a tested release build. Do not submit web screenshots as native-app screenshots when controls or behavior differ.

## Brand direction

- Bright white/light-gray interface.
- One primary blue accent.
- App icon uses the existing ReelScribe `R` mark, but the final store icon must be redrawn/exported at store quality.
- No social-platform trademarks inside the app icon.
- No unsupported claims such as “all links,” “instant,” “perfect,” or “100% accurate.”

## Apple assets

- 1024×1024 App Store icon, opaque, no alpha channel.
- Current required iPhone screenshot sizes generated from the release build.
- iPad screenshots only when iPad distribution is enabled.
- Optional app preview video showing a truthful local workflow.

Recommended screenshot story:

1. Paste a public link or select a local file.
2. Public captions first; local AI remains on device.
3. Device-aware model selection and verified download.
4. Processing progress and cancellation/checkpoint behavior.
5. Editable transcript and timeline.
6. TXT/SRT/VTT export.
7. Native OCR for burned-in subtitles.

## Google Play assets

- High-resolution app icon.
- Phone screenshots from a signed/internal release build.
- Tablet screenshots only when tablet support is declared.
- Feature graphic.
- Optional preview video.

## Screenshot content rules

- Use media owned by PAQ or an explicitly licensed demo clip.
- Remove names, notifications, account identifiers and personal media.
- Show realistic processing time and model size.
- Do not show private Instagram/YouTube content or imply access-control bypass.
- Do not show low-confidence OCR/ASR output as a successful result.
- Show the privacy statement near local processing where readable.

## Localization

Produce at least:

- Traditional Chinese (Taiwan).
- English (United States).

Add Japanese or Korean only after UI localization and support coverage are complete.

## Final verification

- No clipping at system font scaling.
- No status bar, home indicator or navigation overlay hiding controls.
- App name and icon match the signed binary.
- Screenshots match the current release features.
- Privacy/support URLs are publicly accessible.
- Marketing copy matches `zh-TW.md`, `en-US.md`, App Privacy and Data Safety answers.
