# Model Download Consent Copy

## Tiny

```text
下載 Whisper Tiny（約 75 MB）

這個模型會保存在你的手機，用來離線產生字幕。下載後可在沒有網路時使用，也可以隨時在設定中刪除。
```

## Base

```text
下載 Whisper Base（約 150 MB）

Base 通常比 Tiny 更準確，但需要更多空間、記憶體與電量。模型只用於本機辨識，不會取得你的影片或字幕。
```

## Small

```text
下載 Whisper Small（約 500 MB）

此模型只建議高階手機與平板使用。處理時間、發熱與記憶體用量會增加。下載前會再次檢查剩餘空間與裝置狀態。
```

## Large v3 Turbo

```text
下載旗艦模型

這是大型可選模型，可能超過 1 GB。只建議支援且已通過實測的旗艦裝置，並建議使用 Wi-Fi 與充電狀態。下載與載入期間不會同時執行其他大型 AI 工作。
```
