## Full description

ReelScribe is an offline-first video subtitle utility.

Paste a public YouTube or Instagram link, or choose a video or audio file from your device. ReelScribe checks for public captions first. When no public caption track is available, the app can use on-device speech recognition and local frame OCR.

Key features:

• Public caption and timeline import
• On-device Whisper transcription
• Speech enhancement and background-music reduction
• Local OCR for burned-in subtitles
• Long-media chunking and checkpoint/resume design
• Editable transcript and timeline
• TXT, SRT, and VTT export
• Device-aware Tiny, Base, Small, and Large-v3-turbo model tiers
• Model integrity verification and user-managed downloads

Privacy by design:

• Local mode does not intentionally upload selected video, audio, frames, or transcripts
• No social account password, cookie, or private token is requested
• The first release contains no advertising or cross-app tracking SDK
• Models are downloaded only after an explicit user action and can be removed

Some social platforms, private posts, login-only media, regional restrictions, paywalls, or DRM-protected content may not be available. ReelScribe does not bypass platform access controls. Transcription accuracy varies with language, accent, noise, music, image quality, and model tier; review important text before publishing or relying on it.

## Review notes

ReelScribe is an offline-first transcription utility and requires no login. Reviewers can select a local sample video using the system document picker. Tiny/Base models download only after an explicit user action and are SHA-256 verified in release builds. Public YouTube caption mode processes public caption text only. Public Instagram resolution is best-effort and does not use account cookies. Private or restricted content is unsupported. OCR and speech transcription run on device in local mode.
