# ReelScribe FAQ

## ReelScribe 會把影片上傳嗎？

本機模式不會。影片、音訊、OCR 畫面與字幕在手機上處理。貼公開連結時，公開網址會送到解析服務以尋找公開字幕或短效公開媒體。

## 需要帳號或 API Key 嗎？

規劃中的第一版不需要帳號，也不要求使用者提供 API Key。

## 所有 Instagram 或 YouTube 連結都能成功嗎？

不能保證。私人、登入限定、付費、地區／年齡限制、已刪除或 DRM 內容不支援；平台也可能隨時改變匿名公開介面。

## 哪個模型最適合？

Tiny 適合手機、長影片與快速預覽；Base 適合一般品質；Small 與 Large-v3-turbo 只在高階裝置、空間和真機測試條件通過時開放。

## 為什麼不把所有最新模型都放進 App？

同時放入所有模型會大幅增加 App 大小、下載時間、記憶體、耗電、授權和供應鏈風險。ReelScribe 只啟用經過授權、完整性、裝置與品質驗證的模型。

## 可以辨識音樂歌詞嗎？

部分模型可以嘗試，但歌聲與背景音樂會降低準確率。語音強化可能不適合歌曲，應允許使用者關閉；結果仍需校對。

## 可以離線使用嗎？

選定模型下載並驗證後，本機檔案辨識可離線進行。公開連結與首次模型下載需要網路。

## 可以刪除模型和字幕嗎？

可以。正式 App 會提供模型管理、專案刪除、快取清除與匯出功能。
