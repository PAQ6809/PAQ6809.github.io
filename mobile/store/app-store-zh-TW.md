## Description

ReelScribe 是一款以隱私與本機處理為核心的影片字幕工具。

你可以貼上公開 Instagram、YouTube 或其他支援平台的影片連結。系統會先尋找公開人工字幕或自動字幕；來源沒有公開字幕時，可選擇手機中的影片或音訊，使用本機 AI 產生逐字稿和時間軸。

主要功能：

• 公開影片連結字幕查詢
• 本機 Whisper 語音辨識
• 背景音樂與非語音區段抑制
• 讀取影片中已燒錄的畫面字幕
• 長影片分段處理與時間軸合併
• 低可信、重複或亂碼字幕攔截
• 可編輯完整逐字稿
• 匯出 TXT、SRT、VTT
• 透過 iOS 分享選單儲存或傳送字幕檔
• 不需要社群帳號密碼或私人 Cookie

隱私設計：

本機檔案、語音辨識與畫面 OCR 會在目前裝置處理。公開連結功能只處理公開網址；私人、登入限定、地區限制、付費牆或 DRM 內容不支援繞過。部分公開平台可能沒有字幕，或可能阻擋匿名解析，ReelScribe 會顯示限制並提供本機備援，不會把貼文說明冒充成影片語音字幕。

大型或選用 AI 模型可能需要額外下載。下載前會顯示用途與大小，並可由使用者管理或清除。

請只處理你有權使用的影片與字幕內容。

## Reviewer Notes Draft

The app does not require an account. Use a public YouTube video with public captions to test the text-only caption path, or select a local video/audio file to test on-device transcription. Screen OCR reads only visible burned-in text from local video frames. Public Instagram resolution is best-effort and does not support private or login-restricted content. Optional model downloads are not required for the basic workflow.
