前往環境部空氣品質監測資料

應用特色

  • 直接導向 環境部「空氣品質監測站基本資料」，取得官方站點清單。
  • 支援關鍵欄位：站點名稱、AQI、PM2.5、PM10、發布時間。
  • 使用者可下載 JSON 或 CSV，並整合至自有儀表板或通知服務。

搜尋網路相關資料

輸入關鍵字，快速搜尋與「高雄 空氣品質」相關的官方與網路資訊。

搜尋將在新分頁開啟，帶入「高雄 空氣品質 + 關鍵字」查詢。

高雄常見關注

  • 細懸浮微粒（PM2.5）：冬季與東北季風時需特別留意。
  • 靠港工業區鄰近站點：鼓山、楠梓、大寮等 AQI 變化較敏感。
  • 建議依官方發布時間更新資料，避免舊值造成誤判。

建置方向：純軟體與軟硬體整合

方向一

純軟體數據整合

  • 資料源：環境部開放資料「空氣品質指標（AQI）」 API，含站點、AQI、PM2.5、PM10、O3、風向/風速。
  • 後端：Python（FastAPI / Flask），可設排程每小時抓取高雄測站資料。
  • 資料庫：PostgreSQL 或 SQLite，用於儲存歷史資料，支援 24 小時/一週趨勢圖。
  • 前端：React / Vue + Leaflet 地圖 + Chart.js / ECharts 視覺化。
  • 加值功能：分區警示（例：楠梓 PM2.5 > 35 推播）、風向疊圖、儀表板嵌入。
方向二

軟硬體整合（IoT）

  • 主控：ESP32 / Raspberry Pi 搭配 PMS5003、PMS7003 粉塵感測器。
  • 通訊：MQTT 將感測數據回傳伺服器，補足社區或校園監測。
  • 資料庫：InfluxDB（時間序列最佳化）搭配 Grafana 儀表板快速出圖。
  • 用途：自建站點、對比官方測站、量測校園或住家陽台空氣。

實作路線圖（MVP 建議）

  1. 申請環境部 API 金鑰：data.moenv.gov.tw
  2. 撰寫 Python 範例：抓取高雄市各測站的即時 PM2.5 / AQI。
  3. 地圖呈現：Leaflet 標記測站座標，依污染程度套用綠/黃/橘/紅。
  4. 自動化：以 cron / 排程每小時更新資料並快取，避免過期數值。

進階：加入推播訂閱（Web Push / Line Notify），或在圖表中加入風向箭頭、工業區位置對照。

熱門監測站快速連結

  • 高雄全市即時數值
  • 各站 CSV 下載
  • 空氣品質 AQI 小時值（API）

如何使用資料

  • 透過 API 串接：定期呼叫官方 API 更新站點與 AQI。
  • 以 CSV 批次匯入：下載最新檔案後導入 BI 工具或試算表。
  • 視覺化展示：可在圖表中並列 AQI、PM2.5 趨勢並加入警戒線。

數據來源可信度

  • 資料由環境部環境管理署發布，遵循官方維運頻率。
  • 開放授權，適合研究、報導及社群專案再利用。
  • 若遇資料暫停更新，請以官方公告時間為準。

高雄在地化加分題

  • 工業區連動：標記林園、大社、楠梓等工業區與下風處居住區，觀察風向與污染關聯。
  • 交通尖峰：特別監看 08:00、18:00 機車尖峰時段的 PM2.5/AQI 變化。
  • 社區參與：鼓勵自建感測站與官方站點對照，建立在地社群版的「共同監測」地圖。
